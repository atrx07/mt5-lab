# XAU lab tools

Broker/data maintenance utilities live here rather than in `../scripts/`.

- `xau_probe.py` — MT5 contract/environment probe;
- `export_xau_ticks.py` — historical tick exporter;
- `capture_recent_xau_ticks.py` — recent clock-audited tick capture;
- `archive_dataset.py` — deterministic archive/manifest helper;
- `restore_dataset.py` — hash-verified raw-dataset restoration.

These are utilities, not strategy versions.
