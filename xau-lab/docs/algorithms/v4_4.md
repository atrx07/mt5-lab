# V4.4 — MICRO structural engine + Candidate K management

Status: **locked fractional research version**

V4.4 starts from the parity-corrected V4.3 PRIMARY/SECONDARY architecture and adds a third MICRO engine designed to create more trades without simply loosening the older entry gates.

Any parameter or structural change after this lock becomes **V4.5**.

## Replay-parity foundation

The V4.4 lock first resolves the large V4.3 reporting discrepancy.

The canonical V4.3 +₹603.60 figure was produced by:

1. running each of five chronological research segments from a fresh ₹500 balance;
2. recording each segment return independently;
3. compounding those five return factors in chronological order.

It was not a literal one-pass continuous replay.

The V4.3 archived search row also applied its $4 minimum channel range, |m30| >= $1.50 and max($0.50, 0.02 × range) breakout buffer globally. Earlier prose had incorrectly described those breakout-geometry parameters as high-regime-only.

V4.4 uses the corrected semantics and the same reset-segment / compounded-return accounting for its headline capture measurements.

## PRIMARY and SECONDARY

PRIMARY remains the V4.3/V4.1 trend-pullback engine.

SECONDARY retains the parity-corrected V4.3 breakout geometry globally:

- 120-second prior channel;
- channel range >= $4;
- breakout buffer = max($0.50, 0.02 × channel range);
- |30-second momentum| >= $1.50.

The high-activity regime still controls:

- shorter PRIMARY/SECONDARY cooldowns;
- permission for SECONDARY to trade inside the slow directional gate;
- alternate V4.3 exit behavior.

## MICRO entry engine

MICRO is a structural short-horizon pullback/resumption engine.

A BUY candidate requires:

- 120-second momentum >= +$6;
- 60-second momentum >= +$2;
- an actual 10-second counter-move <= -$0.50 occurred within the previous 30 seconds;
- current 10-second momentum >= +$0.20;
- 60-second path efficiency >= 0.12;
- 60-second range >= $2;
- 10-second raw-tick imbalance >= 0;
- 10-second quote rate / 30-second quote rate >= 0.65;
- spread <= 25% of the 60-second range;
- hard spread cap <= $0.30;
- MICRO cooldown >= 60 seconds.

SELL is symmetric.

PRIMARY -> SECONDARY -> MICRO remains the deterministic shared-slot priority. The arbitration experiments did not justify replacing that order.

## MICRO exit / management — Candidate K

Candidate K is the locked management configuration:

- emergency stop: $4;
- take profit: $10;
- max hold: 900 seconds;
- 300-second momentum reversal exit;
- trail trigger: +$4;
- trail give-back: $2;
- stagnation exit after 45 seconds if peak favorable move is still below +$0.75;
- once favorable move reaches +$5.50, realize 75% of the synthetic MICRO exposure;
- the remaining 25% continues under the same TP / trail / stop logic.

The partial realization only reduces exposure after a favorable move. It does not increase entry risk.
