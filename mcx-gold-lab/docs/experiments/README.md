# Experiments

Numbered experiment records live here. One file per experiment:
`NN-short-name.md`. The record states the hypothesis, the frozen setup, the
data used, the outcome, and the verdict (promote / reject / revise).

Rejection is the normal outcome. A rejected experiment with a clear autopsy is
worth more than an ambiguous "promising" one.
